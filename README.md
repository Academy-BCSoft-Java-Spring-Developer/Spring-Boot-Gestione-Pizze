# Spring-Boot-Gestione-Pizze

Applicazione Spring Boot per la gestione e configurazione degli ordini in pizzeria.

## Tecnologie usate
- Java 17
- Spring Boot
- Spring Framework (Dependency Injection, Java Configuration)

## Struttura e Componenti
- **Model**: `Pizza`, `Ordinazione`
- **Config**: `PizzeriaConfig` per la configurazione dei bean di contesto
- **Core**: `GestionePizzeApplication`
